# brand-logos/ — 企業ロゴ画像置き場(s05 用)

> ファイルを下記のパスに置くだけで、自動的にスライド上にロゴが表示される。
> 画像が無いタイル(または読み込み失敗)はテキスト表示にフォールバックする。
> したがって**ロゴが集まったものから順次差し込み可能**。

## 命名規則

すべて **小文字 + ハイフン区切り + .png(または .svg)** で配置する。

## 推奨スペック

- **形式**: PNG(透過背景)または SVG
- **高さ**: 短辺 80–120px 程度(タイル内で max-height 48px 表示)
- **背景**: 透過必須(白背景タイルに乗せるため)
- **余白**: ロゴ周りの余白を切り詰めたタイト版を推奨

## ライセンス・利用許諾

各社ロゴは商標であり、無許諾使用は不可。
以下のいずれかに該当する場合のみ配置してください。

1. 公式のブランドガイドラインで「実績提示用途での使用可」と明示されているもの
2. 個別に許諾を得たもの
3. 案件成果物として公式に「ロゴ掲載可」とされているもの(契約書・指示書ベース)

不明な場合はテキストタイルのまま運用。
